# Specs

This directory holds the canonical OpenSpec specifications for stable capabilities in `easyChat`.

Recommended organization:

```text
openspec/specs/
  <capability-name>/
    spec.md
```

Examples:

- `openspec/specs/auth/spec.md`
- `openspec/specs/friends/spec.md`
- `openspec/specs/conversations/spec.md`
- `openspec/specs/electron-desktop/spec.md`

Use this directory for requirements that represent the current accepted behavior of the system.

Current suggested capability map for this repository:

- `auth`
- `friends`
- `privacy`
- `conversations`
- `groups`
- `messaging`
- `files`
- `favorites`
- `desktop-shell`
