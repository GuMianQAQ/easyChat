# Changes

This directory holds proposed or active OpenSpec changes.

Recommended structure:

```text
openspec/changes/
  <change-name>/
    proposal.md
    design.md
    tasks.md
    specs/
      <capability-name>/
        spec.md
  archive/
```

Use `openspec/changes/<change-name>/` for work that is being explored, proposed, or implemented.

Use `openspec/changes/archive/` for completed changes that have already been merged into the main specs.
